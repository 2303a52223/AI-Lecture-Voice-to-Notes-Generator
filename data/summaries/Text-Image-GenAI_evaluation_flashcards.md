# Flashcards — Text-Image-GenAI (Evaluation)

- Q: What is round‑trip evaluation?
  A: Generate image from prompt → caption image → compare caption to original prompt (semantic metrics).

- Q: Which metric measures image quality?
  A: FID (Fréchet Inception Distance).

- Q: Which metric measures semantic alignment between image and text?
  A: CLIPScore.

- Q: Name one perceptual metric used for image similarity.
  A: LPIPS.

- Q: Why complement automatic metrics with human studies?
  A: Automatic metrics don't fully capture realism, coherence, or bias; humans provide qualitative judgment.
