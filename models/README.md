# Models Cache Directory

This directory stores downloaded AI models for offline use.

## Models Downloaded Automatically:

1. **Whisper Base** (~150MB)
   - Used for speech-to-text transcription
   - Downloads on first transcription

2. **BART Large CNN** (~1.6GB)
   - Used for text summarization
   - Downloads on first summarization

3. **T5 Small** (~240MB)
   - Used for quiz generation
   - Downloads on first quiz creation

## Storage Requirements

- Minimum: 2GB free space
- Recommended: 5GB for optimal performance

Models are cached here to avoid re-downloading on each use.
